# Composition-invariant, explainable machine learning for gastric adenocarcinoma

Analysis code for a study of **why transcriptomic classifiers that look perfect under internal
cross-validation fail on independent cohorts**, and of a single-sample representation that fixes it.

The pipeline reproduces every number, table and figure in the manuscript from the GEO accession
numbers alone. No private data are used and no GPU is required.

## What the study does

Two tasks are run over six public gastric-tissue cohorts (n = 1,246):

1. **Detection** — gastric adenocarcinoma vs non-malignant gastric mucosa. An eight-gene panel is
   derived on a discovery cohort under a leakage-free protocol (feature selection repeated inside
   every resampling fold) and validated on three fully independent cohorts.
2. **Risk assessment** — a 25-gene prognostic panel for three-year mortality, developed on one
   cohort, validated on another, and benchmarked against pathological stage.

Two normalisation strategies are compared throughout under otherwise identical conditions:

| | Strategy | Depends on the test batch? |
|---|---|---|
| **N1** | Cohort-wise gene z-score (the conventional baseline) | Yes — its parameters are estimated from the batch being predicted |
| **N2** | Within-sample rank transform | No — every inference-time quantity comes from one specimen or from training data |

A controlled case-mix stress test (synthetic batches at tumour fractions of 10–90%, plus in-place
resampling of each real cohort) isolates the effect of batch composition from cohort identity.

## Data

Six series are downloaded from the NCBI Gene Expression Omnibus as processed series matrices; no raw
CEL files are re-normalised, so each cohort keeps the summarisation its originators applied.

| Accession | Platform | Role | n |
|---|---|---|---|
| GSE66229 | GPL570 | Discovery, Task 1 | 400 (300 tumour / 100 normal) |
| GSE54129 | GPL570 | External, Task 1 | 132 (111 / 21) |
| GSE13911 | GPL570 | External, Task 1 | 69 (38 / 31) |
| GSE79973 | GPL570 | External, Task 1 | 20 (10 / 10) |
| GSE84437 | GPL6947 | Development, Task 2 | 433 |
| GSE15459 | GPL570 | External, Task 2 | 192 |

Place the downloaded files in `data/` as follows (this is what `01_prepare.py` expects):

```
data/
  GPL570_platform.txt      GPL6947_platform.txt
  GSE66229.txt.gz          GSE54129.txt.gz        GSE13911.txt.gz
  GSE79973.txt.gz          GSE84437.txt.gz        GSE15459.txt.gz
  GSE84437_meta.txt        GSE15459_meta.txt      GSE62254_meta.txt
  GSE15459_outcome.xls
```

`download_geo.sh` fetches the series matrices. The platform annotation tables (GPL570, GPL6947) and
the clinical annotation files are downloaded from the corresponding GEO platform and series pages.

## Environment

Python 3.11. No GPU at any stage.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Running the pipeline

Run in order from the repository root. Intermediate arrays are written to `work/`, figures to
`figures/`.

```bash
bash download_geo.sh             # ~430 MB from GEO
python code/01_prepare.py        # parse series matrices, map probes to gene symbols
python code/02_features.py       # differential expression, leakage-free panel selection
python code/03_detect_models.py  # Task 1: nested CV + 3-cohort external validation
python code/04_prognosis.py      # Task 2: three-year mortality models
python code/04b_prog_oof.py      # survival analysis on out-of-fold risk scores
python code/05_robust.py         # case-mix stress test and N1/N2 comparison
python code/06_xai.py            # TreeSHAP, cross-cohort stability, ablation
python code/07_figures.py        # all manuscript figures
python code/09_diagnose.py       # diagnostics reported in the Results
```

End to end, including the GEO download, the pipeline completes in under three hours on a single
workstation (Intel Core i7-1165G7, 4 cores, 16 GB RAM, Windows 11). The dominant costs are the
repeated nested resampling loops of Tasks 1 and 2, not any single model fit.

All random seeds are fixed, so repeated runs on the same inputs give identical results.

## Figures

`figures/` holds the eleven figures as published. They are regenerated by `07_figures.py`.

## Repository layout

```
code/           the nine analysis scripts, run in the order above
figures/        manuscript figures (regenerated by 07_figures.py)
data/           GEO downloads (not tracked; see Data above)
work/           intermediate arrays and result JSON (not tracked; created by the pipeline)
```
